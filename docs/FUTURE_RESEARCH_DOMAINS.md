# Future Research Domains

These domains are explicitly research topics. They are not runtime policy,
capability grants, or claims that TRIADA implements AGI.

- AI-assisted system design: which architecture decisions can be safely
  delegated while preserving auditability?
- Recursive improvement: how can a playbook propose changes to itself without
  bypassing human approval and replay comparison?
- Scientific research: how should conflicting evidence, uncertainty, and
  parameter influence be represented for novel questions?
- Social and economic impact: which roles change as bounded agent systems become
  more capable, and which safeguards are required?

Every future-domain run must use the same evidence, resource, capability, and
human-gate contracts as ordinary research.
